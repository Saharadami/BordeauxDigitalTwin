## Bordeaux Digital Twin

A smart city digital twin simulation built with SUMO and Unity + Cesium.

### What this project does
- Loads the real road network of Bordeaux (inner ring) from OpenStreetMap
- Simulates vehicle traffic using SUMO traffic simulator
- Visualizes vehicles on a real 3D map using Cesium for Unity

### Stack
- SUMO 1.27 — traffic simulation
- Unity 2022.3 — 3D visualization
- Cesium for Unity — real-world georeferenced map
- OpenStreetMap — road network data

### Status
Work in progress — internship project, future PhD research direction.
Research focus: impact of weather conditions on urban traffic and air pollution modeling using DEVS formalism.
